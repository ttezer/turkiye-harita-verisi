# Mahalle Manual

Bu klasör kullanıcıdan sonradan gelecek manuel mahalle dosyaları için ayrılmıştır.

Kurallar:

- default build bu klasörü otomatik kullanmaz
- yalnızca manuel mahalle modu açıkken okunur
- her il veya veri grubu ayrı alt klasörde tutulmalıdır
- ham dosya adları mümkün olduğunca kaynağı yansıtmalıdır

Beklenen kullanım:

- `source/mahalle-manual/<il-kodu-veya-ad>/`

Bu klasör aktif açık veri yayını yerine geçmez; sadece manuel ekleme ve dönüşüm işleri içindir.
