# Harita Genel Mudurlugu Referansi

Bu repo icinde ham `RAR` veya acilmis `SHP` seti tutulmaz.

Yalnizca referans notu:

- Urun sayfasi: `https://www.harita.gov.tr/urun/turkiye-mulki-idare-sinirlari/232`
- Indirme baglantisi: `https://www.harita.gov.tr/uploads/files/products/turkiye-mulki-idare-sinirlari-1843.rar`

Not:

- Incelenen set `il` ve `ilce` polygonu degil, sinir cizgileri (`LineString`) icerir.
- Bu nedenle varsayilan il/ilce polygon kaynagi olarak kullanilmaz.
- Gerekirse yalnizca referans veya sinir overlay incelemesi icin ayrica indirilebilir.
